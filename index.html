Frequently Asked Questions

Are my private media files safe?

Yes. NovaConvert operates entirely inside your local browser memory sandbox. Your video files are never uploaded to any remote web server or cloud storage infrastructure, offering complete privacy isolation.

Does this consume my mobile data connection balance?

No. Once the web app page asset code has been cached by your browser, all heavy video processing algorithms happen using local device computation streams. No internet connection bandwidth is used for converting files.
